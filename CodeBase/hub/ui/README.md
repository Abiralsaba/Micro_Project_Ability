# Hub Admin UI

Touchscreen interface for the 7" DSI display on the Central Hub.

## Features

- User profile management (add/edit modules, set disability type)
- Contact list (pair with remote hubs/users)
- Live status dashboard (connected modules, message activity)
- Conversation history viewer
- Health monitoring alerts
- System settings (WiFi, MQTT config)

## Files to Create

| File | Purpose |
|---|---|
| `app.py` | Main UI application (Flask web or PyQt native) |
| `templates/` | HTML templates (if using Flask) |
| `static/` | CSS, JS, assets (if using Flask) |
