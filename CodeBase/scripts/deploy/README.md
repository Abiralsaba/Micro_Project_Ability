# Scripts — Deploy

Deployment scripts for pushing updates to hubs and modules.

## Files to Create

| File | Purpose |
|---|---|
| `deploy_hub.sh` | Deploy updated hub software to RPi 5 via SSH |
| `deploy_module.sh` | Deploy updated Python code to RPi Zero 2W modules via SSH |
| `deploy_cloud.sh` | Deploy updated Mosquitto config to VPS |
