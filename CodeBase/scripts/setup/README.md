# Scripts — Setup

Environment setup scripts for each component.

## Files to Create

| File | Purpose |
|---|---|
| `setup_hub.sh` | Central Hub setup — install dependencies, configure Mosquitto, Vosk, Piper |
| `setup_zero.sh` | RPi Zero 2W setup — install MediaPipe, TFLite, camera config |
| `setup_cloud.sh` | Cloud VPS setup — install Mosquitto, TLS certificates, ACLs |
